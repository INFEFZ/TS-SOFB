## Handlungskompetenz

Die dipl. Techniker HF Systemtechnik verstehen Maschinen und Anlagen als Systeme. Sie wirken bewusst auf ein System ein und sind sich den Auswirkungen klar. Sie gehen beim Entwicklungsprozess von Softwareprogrammen systematisch vor und kennen die einzelnen Prozessschritte.
