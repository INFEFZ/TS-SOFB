## Lernziele

- [x] Kennt die Möglichkeiten von Editoren sowie einer Entwicklungsumgebung, sowie den Umgang mit Fehler- und Warnmeldungen.
- [x] Kennt den grundlegenden Aufbau einer Applikation resp. Programmes.
- [x] Kennt die Verwendung von Kontrollstrukturen wie Iterationen (vor-/nachgeprüft), Selektion.
- [x] Kennt Sinn und Zweck von Variablen und Konstanten sowie deren Unterschied.
- [x] Leitet aufgrund der Vorgaben die erforderlichen Daten (Eingabe, Verarbeitung, Ausgabe und ihre Datentypen) ab.
- [x] Kennt die Funktionsweise einer Software nach dem EVA Prinzip.
- [x] Implementiert die Applikation mit Hilfe von Kontrollstrukturen und selbst erstellten Funktionen.
- [x] Kennt den Zweck, die Funktionen und die Bedienung eines Debuggers.
- [x] Hält vorgegebene Konventionen ein, kommentiert den Code und achtet dabei auf die Wartbarkeit.
- [x] Interpretiert Mängel (Fehler) in der Software und korrigiert diese.
